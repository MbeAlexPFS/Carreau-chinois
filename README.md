# Carreau Chinois

Carreau chinois est une version personnalisée du jeu Carré Chinois. Il dispose des fonctionnalités suivantes :
- Un mode contre IA (Facile, Normal, Difficile)
- Un mode multijoueur à écran partagé
- Choix entre 3 et 4 pions
- Choix entre deux cadres de jeux (3x3 et 5x5)
- Possibilité de changer l'ordre de jeu
